## Возможности

- **Заметки на рабочем столе**: отдельные окна, перемещение, изменение размера, закрепление поверх окон, блокировка, избранное и мягкие тени.
- **Сворачивание к краю**: кнопка превращает заметку в узкую вкладку справа. Наведение открывает просмотр, не закрывая другие вкладки; при переключении предыдущий просмотр сворачивается. Щелчок или перетаскивание оставляет заметку открытой.
- **Markdown**: заголовки, полужирный и курсивный текст, списки, задачи, предпросмотр и экспорт `.md`.
- **Рабочая область**: поиск, все и избранные заметки, цвета, темы, автозапуск и управление из трея.
- **ИИ / MCP**: локальная служба позволяет ИИ создавать, читать, редактировать, дополнять, показывать, скрывать и удалять заметки.
- **Языки**: упрощённый и традиционный китайский, английский, японский, корейский, немецкий, французский, испанский, португальский, русский и арабский. Выбор вручную или по системе; для арабского предусмотрен RTL.
- **Локальное хранение**: данные остаются в папке текущего пользователя Windows. Учётная запись приложения и облачная синхронизация не требуются.

Официально поддерживается **Windows 10/11 x64**. Другие платформы и Windows ARM64 пока не входят в сборку и проверку.

## Установка и обновление

Скачайте `Memo Desktop Setup <version>.exe` со страницы **Releases** этого репозитория. Сверьте хеш с `SHA256SUMS.txt` того же выпуска:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Memo Desktop Setup <version>.exe'
```

Перед обновлением завершите старую версию через трей. Установщики пока не имеют цифровой подписи Windows; приложение не скачивает обновления автоматически.

Отправка тега `v<package.json.version>` запускает выпуск. До первого релиза установщика может не быть. См. [руководство по выпуску](../RELEASING.md) на английском.

## Запуск из исходного кода

Нужны **Windows x64, Node.js 22.12 или новее, npm и Git**. Клонируйте репозиторий и выполните в его корне:

```powershell
npm ci
npm start
```

После установки зависимостей можно дважды щёлкнуть [`start.cmd`](../../start.cmd). Он собирает и запускает текущие исходники, а не старый exe из `release`. Другие версии сначала завершите через трей.

`npm start`, `start.cmd` и установленное приложение используют общий файл `%APPDATA%\Memo\memo.json`. Перед разработкой закройте приложение и сделайте резервную копию. `npm run dev` — только браузерный предпросмотр без настоящих окон, трея и службы MCP.

### Команды разработки

| Команда | Назначение |
| --- | --- |
| `npm ci` | Установить зависимости по lock-файлу |
| `npm start` | Собрать и запустить локальное приложение Electron |
| `npm run dev` | Открыть браузерный предпросмотр Vite |
| `npm test` | Проверить данные, сворачивание, языки, запуск и выпуск |
| `npm run build` | Проверить типы и собрать интерфейс |
| `npm run runtime` | Подготовить и проверить среду Electron для Windows |
| `npm run check:i18n` | Проверить 11 языков и RTL в скрытых окнах; сначала собрать проект и подготовить среду |
| `npm run check:dpi` | Проверить DPI и вкладки на подключённых экранах; сначала собрать проект и подготовить среду |
| `npm run pack` | Собрать распакованное приложение в `release/win-unpacked` |
| `npm run dist` | Создать установщик NSIS без публикации |
| `npm run package:win` | Упаковать готовую сборку в установщик Windows x64 |
| `npm run release:check` | Проверить версии и журнал; при заданном RELEASE_TAG проверить и тег |
| `npm run release:prepare` | Подготовить файлы выпуска и контрольные суммы локально, без загрузки |

Проверка CI на одном экране не заменяет реальные тесты с разными DPI. При изменении работы между экранами следуйте руководству для участников.

## Использование заметок

- Перемещайте заметку за ручку верхней панели; заголовок можно редактировать прямо в ней.
- Булавка держит заметку поверх других окон, звезда добавляет её в избранное. Эти состояния независимы.
- Блокировка скрывает инструменты и запрещает менять заголовок, текст, цвет, положение и размер. Перед удалением разблокируйте заметку; звезду и закрепление менять можно.
- Обычная заметка сворачивается только кнопкой, а не при потере фокуса или приближении к краю. Сначала открепите её. При отключении бокового сворачивания кнопка скрывается.
- Наведите на вкладку примерно на 0,15 секунды. Просмотр остаётся открытым над исходной вкладкой, промежутком или заметкой; после выхода из всех зон сворачивается примерно через 0,45 секунды. Щелчок, перемещение или изменение размера оставляют окно открытым.
- Закрытие заметки скрывает её; удаление в рабочей области стирает содержимое. При закрытии рабочей области приложение остаётся в трее.
- В настройках доступны тема, цвет по умолчанию, язык, автозапуск, запуск в трее и сворачивание к краю.
- Путь к данным указан в настройках. Перед копированием или восстановлением memo.json завершите приложение.

## Подключение ИИ / MCP

Скопируйте конфигурацию из раздела **ИИ и MCP** в клиент с поддержкой stdio MCP. Приложение должно оставаться запущенным. Установленная версия использует Node-режим Electron, отдельная установка Node.js не нужна. Для разработки можно использовать системный Node; замените путь в примере на путь к вашему проекту:

```json
{
  "mcpServers": {
    "memo": {
      "command": "node",
      "args": [
        "C:/path/to/memo-desktop/electron/mcp.cjs"
      ]
    }
  }
}
```

| Инструмент | Назначение |
| --- | --- |
| `memo_list` | Список заметок и состояний |
| `memo_create` | Создание с цветом, закреплением, блокировкой и звездой |
| `memo_update` | Изменение заголовков, текста, цветов и состояний |
| `memo_append` | Добавление текста к существующему содержимому |
| `memo_show / memo_hide` | Показ или скрытие заметок |
| `memo_delete` | Удаление разблокированных заметок |

Пример: «Создай зелёную заметку с планом на неделю, добавь три задачи и отметь звездой».

MCP передаёт запросы главному процессу через локальный именованный канал текущего пользователя и не пишет файл напрямую. При включённом MCP подключённые клиенты могут читать и изменять заметки, соблюдая блокировку. Рендереры используют sandbox и context isolation с отключённой Node integration. Markdown не загружает внешние изображения и не открывает ссылки автоматически. См. [описание безопасности](../../SECURITY.md) на китайском.
